# TSP-005 — `agent-run` records tokens and a tool histogram per run in `index.tsv`

## Problem
Every headless run gets the full 7 kB preamble plus its brief, but no agent's `logs/index.tsv` records tokens or tool calls, so preamble overhead and "did it use the web / pc" cannot be measured.

## Evidence
- `*/logs/index.tsv` header — `start end exit seconds cost_usd log`; collector: "no token columns".
- `AGENT-PREAMBLE.md` — 7027 bytes (~1.8 k tokens) sent on every run of 6 agents.
- `adapters/claude/run:9,17` — `--output-format json`; only `total_cost_usd` and `usage` are kept, no per-tool events.
- `bin/pcbench:270-292` — already parses `stream-json` into `tokens` + `tool_histogram`; the runner does not reuse it.

## Survey
- exists: Claude Code headless docs, `--output-format stream-json --verbose` gives one line per `tool_use`, final `result` has `usage.{input,output,cache_read_input,cache_creation_input}_tokens`, https://code.claude.com/docs/en/headless (read 2026-09-07); known caveat: JSONL transcript `usage.input_tokens` are placeholders, only the `result` line is final, https://github.com/anthropics/claude-code/issues/28197 (read 2026-09-07).
- chosen: adapter switches to `stream-json --verbose`, keeps writing the `result` object to `RAW_OUT`, and writes `tokens_in tokens_out cache_r tool_calls histogram` to `META_OUT`; `agent-run` appends those columns (new header only when the file is created; old files get the new header via a one-time `index.tsv` rewrite).
- why: same parser as pcbench, no new dependency; unlocks the preamble `--brief` decision with a number.

## Proposed change
`adapters/claude/run`, `bin/agent-run`, `bin/toolsmith-inputs` (`tokens` section). Test: `bin/tests/agent-run.test.sh` with a stub `claude` that prints a canned stream.

## Success check
- metric: cache-miss input tokens per run, median over the six agents
- before: 0 token columns in `index.tsv`
- target: number in `index.tsv` for every run from the next week; follow-up proposal targets −40 % via a bash-first preamble
- measured by: `toolsmith-inputs --json | jq .tokens`
