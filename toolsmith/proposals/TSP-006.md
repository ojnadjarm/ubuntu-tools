# TSP-006 — Audit hook matcher: log WebSearch, WebFetch, Read, Grep, Glob, Agent

## Problem
`log/actions.jsonl` only sees Bash/Edit/Write/MCP calls, so an agent's reads and web use are invisible to `agents-log`, the digest and the toolsmith.

## Evidence
- `~/.claude/settings.json:39` — `"matcher": "Bash|Edit|Write|MultiEdit|NotebookEdit|mcp__.*"`.
- `adapters/claude/settings.fragment.json` — same matcher (the fragment is the source the installer merges).
- `state/inputs.json` audit — 211 sessions, not one WebSearch/WebFetch/Read row; this run alone made 7 web calls.

## Survey
- exists: hooks reference lists `Read, Glob, Grep, WebFetch, WebSearch, Agent` as matchable PostToolUse names and `*` for all, https://code.claude.com/docs/en/hooks (read 2026-09-07).
- chosen: matcher `*`, and `audit-log.py` summarises non-Bash tools by `file_path` / `query` / `url` only (no content), keeping row size < 300 B.
- why: one line of config; the hook already handles unknown tools via `tool_name`.

## Proposed change
`adapters/claude/settings.fragment.json` matcher → `*`; `adapters/claude/hooks/audit-log.py` summary rules for Read/Grep/Glob/WebSearch/WebFetch/Agent; `adapters/claude/install` (merge) re-run by the owner since `~/.claude/settings.json` is theirs.

## Success check
- metric: distinct tool names in `agents-log --since 7d --stats`
- before: 5 (Bash, Edit, Write, MultiEdit, mcp)
- target: ≥10 including WebSearch and Read
- measured by: `agents-log --since 7d --stats`

## Effort
- model: sonnet
- sessions: 1
- resident: none (hook overhead +1 python exec per read; watch `pc top` for `python3` wakers)

## Class
owner-go

## Result
Files touched:
- `~/.claude/settings.json` — PostToolUse matcher → `*` (one line; backup at
  `~/agents/state/settings.json.pre-TSP-006`, `diff` shows that line only).
- `adapters/claude/settings.fragment.json` — same matcher, so a fresh install matches.
- `hooks/audit-log.py` — `ARG_KEYS` summary rules: a tool with no `command` field takes its
  main argument (`pattern`, `query`, `url`, `file_path`, `notebook_path`, `path`,
  `description`, `prompt`), redacted, `op` = tool + short arg capped at 60 chars, empty
  input falls back to the JSON blob. `agents-log --stats` still groups on the first token.
- `bin/tests/audit-redact.test.py` — 8 fixture summary cases plus redaction and truncation.

Validation:
- `python3 bin/tests/audit-redact.test.py` → `all 24 cases pass`.
- `bash bin/tests/toolsmith-proposals.test.sh` → green.
- `bash adapters/claude/install` → `claude adapter: no changes` (fragment matches the merge).
- `pc doctor --quick` → PASS 13/13 before and after.
- Live: two headless `claude -p --model claude-sonnet-5` runs (WebSearch, then
  Glob/Grep/Read/WebFetch on a scratch fixture) produced rows such as
  `WebSearch  WebSearch systemd timer OnCalendar syntax` and `Read  Read notes.txt`.
