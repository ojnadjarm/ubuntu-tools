# TSP-004 — `agents-log --raw`: map every raw tool call to the `pc` verb that covers it

## Problem
Raw tool use rivals `pc` use in the audit log, but nothing says which raw calls had a `pc` equivalent, so the fleet cannot see where the contract or the toolbox is missing.

## Evidence
- `state/inputs.json` audit (4 d): raw=848 vs pc=1118; pactl=485, tailscale=157, powerprofilesctl=74, systemctl restart=50, systemctl stop=35, docker restart=25, wpctl=22.
- `bench/LAST.json` / BASELINE-PCBENCH.md:165 — raw recipes per task +8.1 in the new arm.
- `bin/agents-log:7-12` — flags are `--since --session --grep --stats --pc`; no raw view.

## Survey
- exists: "Unix CLI as the native tool interface" argues agents choose the tool with the best `--help`/exit-code contract, https://agentpatterns.ai/tool-engineering/unix-cli-native-tool-interface/ (read 2026-09-07); PreToolUse rewrite hooks (agent-callable, above) — rejected for now: rewriting commands hides the gap instead of measuring it.
- chosen: `agents-log --raw [--since]`: table `raw verb → pc verb → count → sessions`, mapping in one dict inside the script (`pactl set-default-sink→pc audio sink`, `powerprofilesctl set→pc power profile`, `systemctl (stop|restart)→pc units`, `docker restart→pc docker restart`, `tailscale→pc net tailscale`, `wpctl→pc audio`); rows with no mapping print `—` = a toolbox gap.
- why: measurement first; feeds a later PreToolUse-hint proposal if the number stays high.

## Proposed change
`bin/agents-log`: add `--raw`; `bin/tests/agents-log.test.sh`: fixture `actions.jsonl` under a temp HOME. `toolsmith-inputs` gains the table in `audit.raw_map`.

## Success check
- metric: raw calls with a `pc` equivalent per 7 d (agent sessions only, orchestrator excluded)
- before: unknown (≈316 pc-coverable of 848 by hand count)
- target: number published weekly; 30 % drop after the follow-up hint proposal
- measured by: `agents-log --since 7d --raw`
