## Tracy (native C/C++)
```bash
T=~/opt/gamedev/tracy-0.14.1
clang++ -O2 -std=c++20 -fuse-ld=mold -DTRACY_ENABLE -I $T/public app.cpp $T/build-client/libTracyClient.a -lpthread -ldl -o app
./app & tracy-capture -a 127.0.0.1 -o run.tracy -f; tracy-csvexport run.tracy   # zone name,total_ns,counts,mean_ns,...
```
Fixture: `fixture-tracy/hello.cpp`. Client lib is built `TRACY_ONLY_LOCALHOST=ON`. GUI: `tracy` (owner use).

## Native C++ SDL3 + Vulkan (T457)
```bash
$S/new-cpp-game --build ~/src/mygame                 # template: CMake presets + vcpkg (SDL3, vk-bootstrap, volk), clang + mold + ccache
$S/cpp-ci ~/src/mygame [--profile-frames 300] [--keep]    # build, sanitize, validation run, perf, Tracy profile (9 stages incl. shaders, tidy + golden; GAME_TRACY=ON adds 5 frame zones)
$S/cpp-tidy ~/src/mygame                                  # clang-tidy 21 with the template .clang-tidy; every finding fails (also the cpp-ci `tidy` stage)
cd ~/src/mygame && cmake --build --preset dev        # rebuild (VCPKG_ROOT=~/opt/gamedev/vcpkg)
$S/cpp-vk-run.sh --frames 120 build/dev/game         # Iris Xe under headless weston, validation on; DONE line with avg_fps, rc 2 on errors
```
- Template `templates/cpp-vulkan/`: `main.cpp` (SDL loop, `--frames N`, `--validate`), `gpu_context` (vk-bootstrap instance/device/swapchain), `renderer` (2 frames in flight, dynamic rendering clear; draw calls go in `Renderer::record`).
- First configure builds SDL3 from source (~2.5 min); later projects reuse the vcpkg binary cache (clean build ~10 s, ccache rebuild ~4 s). Delete `build/` and `vcpkg_installed/` at the drop.
- T718 warm ccache in every copy: the `dev` preset (release inherits) carries cpp-ci's T680 settings: env `CCACHE_BASEDIR=${sourceDir}` + `CCACHE_NOHASHDIR=1` (build presets inherit it), `-fdebug-prefix-map=${sourceDir}=.` and `CMAKE_CXX_SCAN_FOR_MODULES=OFF`, so `new-cpp-game --build` and `cmake --build --preset dev` hit the shared cache. A bare `ninja -C build/dev` runs without the preset env.
- Shaders: compile with `glslc` and check with `shader-check.sh`.
- T561 GPU timestamps: `cpp-ci` perf rows carry `gpu_ms_p50/p99` (timestamp queries), `cpu_ms_p50` (frame minus fence/acquire/present waits) and `bound=gpu|cpu`.
- T569 gpu gate: after 3 pass rows, perf fails when `gpu_ms_p50` > `--gpu-tol` (15) % or `gpu_ms_p99` > `--p99-tol` (25) % over the median of the last 10 pass rows.
- T570 `--no-syncval`: `cpp-vk-run.sh` validation runs with VVL sync + best-practices on (+9.7 % median frame time); `--no-syncval` keeps core validation only.
- T640 `cpp-vk-run.sh --size WxH --timeout S`: render size and run timeout (default 60 s) for long captures, e.g. the 32 s trailer replay `templates/cpp-vulkan/input/trailer.json` (3 pickups + win at ticks 118/355/805/1055 since T654 collision) used by `mv-new --kind trailer --game <dir>`.
- T576 real mesh: the template draws `model_lod0.glb` (cgltf, cube fallback); `game --model path.glb` picks another.

- T950 static shader cost: `scripts/shader-stats [--baseline FILE] [--write-baseline FILE] [--json] SHADER...` compiles each shader (`glslang -V`, `spirv-opt -O`, so dead code and inlined calls are folded) and counts function-body instructions, arith (all ALU ops: OpF*/OpI*/OpS*/OpU* incl. int div/mod/compare, OpVector*/OpMatrix*/OpDot, shifts, bitwise, OpBitcast/OpConvert*, OpSelect, logical, + GLSL.std.450 calls), tex (OpImageSample*/Fetch/Gather), branch, loop and barrier; a line reads `post.frag instr 682 arith 486 tex 19 branch 19 loop 1 barrier 0`. `--write-baseline` writes a TSV keyed by basename; `--baseline` adds `(+N)` deltas and `GROW <shader> <metric> +N %` above 10 % (rc 1); a compile error, an extension glslang cannot map to a stage, or a missing glslang/spirv-opt/spirv-dis prints `ERROR <shader>: <cause>` (rc 2, never the GROW rc 1). No GPU, ~0.25 s per shader: run it before a GPU timing run. Template baseline `templates/cpp-vulkan/shaders/stats-baseline.tsv` (8 shaders); the one-pass FXAA costs instr +635, arith +459, tex +16, branch +19 over post.frag without the `fxaa()` call. Pitfall: counts are not ms. T688's FXAA pass measured +0.24-0.30 ms on Iris Xe, and post is bandwidth-bound (T643), so a texture fetch can cost more than 100 ALU ops and a branch that skips most pixels costs little; use GROW to flag a change, then time it with `gpu-gate.sh`.


## CLI flags
Flags of `cpp-ci`, `cpp-tidy`, `cpp-report`, `cpp-vk-run.sh`, `game-ci`, `asset-pipeline.sh` and `bin/gamedev-perf` not shown on a line naming their CLI (`tests/gamedev-cli-doc.test.sh` fails when a `--help` flag of a gamedev CLI is on no doc line, or under no `##` heading, naming that CLI as a whole word).
- `cpp-ci --frames N`: frames of the validation-on `run` stage (default 120).
- `cpp-ci --sanitize-frames N`: frames of the ASan+UBSan `sanitize` run (default 60).
- `cpp-ci --perf-frames N`: frames of the validation-off `perf` run (default 600).
- `cpp-ci --capture-frame N`: frame RenderDoc captures to `OUT/perf/frame.rdc` when the perf gate fails (default 60, T673).
- `cpp-ci --golden-frame N`: swapchain frame the `golden` stage compares with `golden/frame.png` (default 60).
- `cpp-ci --target NAME`: executable target every stage runs (default `game`).
- `cpp-tidy -j N`: parallel clang-tidy jobs (default `nproc`).
- `gamedev-perf --skips [Nd|Nh]`: timing gates' skips.tsv rows per test:metric in the window, WARN when skipped > ran (default 7d, T786).
- `gamedev-perf --compare A B`: two perf-cpp.csv rows (date prefix, -1, -2) or cpp-ci summary.json/OUT dirs per pass, rc 1 when B is over a budget (T857).
- `gamedev-perf --trend [N]`: the last N (14) perf-cpp.csv rows per pass: sparkline, last, median of the earlier rows, % change, budget headroom; WARN + rc 1 when last > 1.15x median and > +0.02 ms; < 3 rows: `no trend yet` (T902).
- `gamedev-perf --json`: `--compare` / `--trend` output as JSON (default text).
- `cpp-report --out FILE`: page path (default `<ci dir>/cpp-report.html`).
- `cpp-report --sheet IMG`: capture contact sheet to inline (default `contact-sheet.jpg` or `*sheet*.jpg|png` in the ci, then project dir).
- `cpp-vk-run.sh --no-validate`: run without Vulkan validation (and without its sync + best-practices checks).
- `game-ci --max-load L`: export and capture wait for load1 < L (default 1 x nproc).
- `game-ci --perf-wait N`: perf waits up to N s for load1 to drop under `--perf-max-load` instead of skipping at once.
- `asset-pipeline.sh --min-psnr-color DB`: PSNR floor for colour KTX2 maps only (default ETC1S 31, UASTC 38; `--min-psnr` overrides every class).
- `asset-pipeline.sh --min-psnr-orm DB`: PSNR floor for ORM KTX2 maps only (default 33).

## Template flags
`build/dev/game [flags]` (`src/main.cpp parse_args`; `tests/cpp-flags-doc.test.sh` fails when a flag lacks a line here or a line names a removed flag).
- `--frames N`: run N frames then exit with a DONE line (default 0 = until closed).
- `--validate`: Vulkan validation layers on (default in Debug builds).
- `--no-validate`: validation off, also in Debug builds.
- `--model PATH.glb`: scene model (default `model_lod0.glb`, T576).
- `--capture N OUT.png`: save swapchain frame N (T593 golden).
- `--crash-test`: null-pointer store for the crash handler fixture (T611).
- `--no-shadows`: skip the shadow pass (T628).
- `--no-ibl`: hemisphere sky instead of image-based lighting (T675).
- `--aa on|off`: FXAA inside the one tonemap pass (default on; any value but `off` is on, T688, one pass since T784).
- `--exposure EV`: tonemap exposure (default 0, T643).
- `--size WxH`: render size (default 1280x720).
- `--record F.json`: record input, one tick per frame (T618).
- `--replay F.json`: replay recorded input deterministically (T618).
- `--capture-every DIR`: dump every frame as PNG (T618).
- `--audio-out F.wav`: render the audio mix in sim time with no device (T639).
- `--hot`: shader hot reload, Debug builds only (T644).
- `--pause-at N`: freeze sim and time at frame N, rendering continues (T644).
- `--camera third|first|x,y,z,yaw,pitch`: camera mode (default third; numeric pose behaves as first, T627/T691).
