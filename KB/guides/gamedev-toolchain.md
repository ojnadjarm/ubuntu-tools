## Pitfalls (measured)
- Xvfb: no DRI3 -> llvmpipe, 8.2 fps; weston headless: Iris Xe, 186.5 fps (same scene, 1280x720).
- RenderDoc 1.46 lacks Wayland WSI: Godot drops to OpenGL3 silently; xwayland capture gave a 7.3 MB Vulkan `.rdc` at 132.7 fps.
- No frame-N flag in `renderdoccmd`; `rd-trigger.so` (LD_PRELOAD, in-app API) triggers after `RD_DELAY` s or at frame `RD_FRAME`; cpp-ci captures `OUT/perf/frame.rdc` on a perf gate fail. RenderDoc: no Wayland WSI, lavapipe shows as Vulkan 1.2. `qrenderdoc --python` hung headless.
- Tracy GUI cmake needs libssl-dev, libdbus-1-dev, libcapstone-dev, wayland/xkbcommon/egl/freetype dev packages; its GCC `-flto` link fails under `-fuse-ld=mold` (undefined `tracy::OpsList`), default ld works (503 objects, ~20 min at -j12 nice).
- Export 13 s, binary 71 MB; first second of a run is shader compile (fps 1-90).
- `godot-mono --import` aborted once on a fresh C# project; rerun clean.

- T454: apt gltfpack 0.22 has no BasisU (`-tc` errors); upstream 1.3 in `~/opt/gamedev/gltfpack-1.3`. Godot 4.7 aborts import on `KHR_mesh_quantization`: pass `-noq`. Demo: 62976 -> 31488 -> 6296 tris, 1.45 MB -> 0.19 MB, all 3 imported with a 512x512 KTX2 texture.
- T454: same fixture ranged 105-297 fps within 20 min while other agents rendered on the GPU (load1 8-40): compare only quiet-machine CSVs. 2 of ~25 smoke runs hung after Wayland init with no fps (cause not found; perfgate retries once, raw log `PROJECT/run.log`; weston wait now 20 s).
- T539: frame-time p99 is the hitch signal avg fps hides: a load-17 run gave avg 45 fps but p99 117 ms vs 26 ms quiet; load is only checked at start, so a parallel GPU job mid-run still pollutes rows.
- T551: at load 5-15 (parallel Blender/C++ builds) gt0 `throttle_reason_status` (PL1) is set in 80-100 % of samples and fixture fps swings 25-126 within one 10 s run; the gate re-runs those as NOISE once, so a busy-box gate takes ~2x. Baseline counts only `PASS` rows, so legacy/noisy rows never move it.
- T598: the PL1 bit is the package power budget shared with CPU load (status 37 % of samples at load 40, GPU at 600 vs 750 MHz requested), so NOISE now counts only hard reasons (thermal, prochot, ratl, vr_thermalert, vr_tdc, pl4): 5 runs at load 38-44 gave 0 NOISE. - Asset cache (T850): `asset-pipeline.sh` caches each gltfpack LOD (key: sha256 of the source + the gltfpack binary + its args) and the Godot import + inspect.gd lines (key: `godot --version` + glb names and bytes + inspect.gd; not stored after an `import FAIL`) in `${ASSET_CACHE:-$XDG_CACHE_HOME/asset-pipeline}` (`~/.cache/asset-pipeline`). Entries carry a SUMS file (a corrupt entry is removed and re-made), a hit prints `ASSET cache hit <label> <sha8>` on stderr, the oldest entries are pruned to `ASSET_CACHE_MB` (512) and `.new.*` staging dirs over 60 min are removed; `ASSET_CACHE=0` turns it off. `tests/asset-budget.test.sh` shares one cache over its 3 cases. Pitfall (T850 verifier): the first cut aborted the whole run under `set -e` when the cache dir was unwritable (rc 1, only `mkdir: Permission denied`, no report.txt); the cache write is best-effort now (`unwritable cache: run still passes` in `tests/asset-cache.test.sh`).
- `gamedev-perf --compare A B [--json]` (T857): A and B are perf-cpp.csv rows (date prefix, -1 last, -2 the one before) or a cpp-ci summary.json/OUT dir; one row per pass + total + p99 + draws with A ms, B ms, Δ ms/%, budget (perf-budgets.json), `over` (B > budget) or `noise` (|Δ| < max(0.02 ms, 3 %)); WARN on a load1 mismatch (> 1 and > 1.5×) or a GPU clock gap (> 10 %, from the run or skips.tsv within 30 min); rc 1 when B is over a budget. Pitfalls (T857 verifier): a CSV row with extra fields gives a TypeError traceback and rc 1, the over-budget code; a missing or unreadable perf-budgets.json turns budgets off with no WARN; `--json` writes a bare NaN for a `nan` cell; the clock WARN always says `(skips.tsv)`. Fixed T902 (read from code 2026-10-20): extra fields -> `bad row N` rc 2; no perf-budgets.json -> `WARN no perf-budgets.json`; NaN -> JSON null; the clock WARN names its source (`run`, `skips.tsv` or `A run, B skips.tsv`).
- `gamedev-perf --trend [N] [--json]` (T902): the last N (default 14) perf-cpp.csv rows per pass (post shadow skin scene frame p99 draws): sparkline, last, median of the earlier rows, % change, budget headroom; WARN + rc 1 when last > 1.15× median and > +0.02 ms; under 3 rows it prints `no trend yet` rc 0 (live 2026-10-20: 1 row).
- `scripts/gpu-gate.sh` (T899): `tests/cpp-aa`, `cpp-shadow`, `cpp-hdr` time through `gpu_timed TEST METRIC -- CMD`; busy (`quiet-gate --max-per-cpu 0.5 --gpu`), lavapipe or a median clock < 90 % of `gt_max_freq_mhz` skip (rc 3) and every call writes one skips.tsv row, so `--skips` sees all three. `GAMEDEV_GPU_PIN=1` raises `gt_min_freq_mhz` to RP0 (Iris Xe 100 -> 1300 MHz) via `sudo -n tee` and restores it in an EXIT trap; under run.sh's sudo shim it runs unpinned. Detail: `reference/cpp-vulkan.md`.
- `cpp-report` (T903): `scripts/cpp-report <project|ci dir> [--out FILE] [--sheet IMG]` writes one self-contained cpp-ci review page (stages, GPU passes vs budget and the previous run, frame stats, VRAM, sanitizer/tidy counts, golden + FLIP, contact sheet; missing parts say `n/a (<why>)`); rc 0 written, 2 bad input. `showcase-page` writes it as `cpp-report.html` beside index.html.
- One glTF reader (T994): `asset_quality.py`, `asset-pipeline.sh --validate` (KTX2 extraction) and motion-video `mv-layout` read glbs through `~/agents/lib/glb.py` (stdlib: load, accessor with byteStride + normalized ints, image_info, clips, skins, tri_count, bounds); each finds it via its realpath, so the `~/.claude/skills` symlinks work (`bin/tests/glb-info.test.sh` 14/14, 1.2 s).
